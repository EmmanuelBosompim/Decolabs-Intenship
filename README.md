# Password Strength Checker

A simple Python program that checks the strength of a password.

## Features

- Checks whether the password has at least 8 characters
- Checks for an uppercase letter
- Checks for a number
- Checks for a symbol
- Calculates a score out of 4
- Classifies the password as WEAK, MEDIUM, or STRONG

## How to Run

Make sure Python is installed, then run:

```bash
python password_strength_checker.py
```

## Example

A password such as `Hello123!` satisfies all four checks and receives a score of 4/4.
