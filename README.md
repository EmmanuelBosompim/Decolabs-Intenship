1. Password Strength Checker
   
A beginner-friendly Python cybersecurity project that evaluates password strength based on four criteria: minimum length, uppercase letters, numbers, and special characters. The program calculates a score out of 4 and classifies the password as Weak, Medium, or Strong. This project demonstrates the use of Python variables, loops, conditional statements, and string methods.

3. Basic Encryption & Decryption
   
A Python project that demonstrates basic encryption and decryption using the Caesar Cipher technique. Users can enter a message and a shift key, after which the program encrypts the message and decrypts it back to its original form. The project demonstrates fundamental concepts of cryptography, character encoding, loops, conditional statements, and string manipulation.

5. Phishing Awareness Triage
   
A beginner-friendly Python cybersecurity awareness tool that analyzes a message for common suspicious keywords associated with phishing attempts, such as “urgent,” “verify,” “password,” “payment,” and “click here.” The program reports detected indicators and reminds users that keyword detection alone does not prove that a message is phishing. This project demonstrates Python lists, loops, string processing, and basic cybersecurity awareness concepts.
